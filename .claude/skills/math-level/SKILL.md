# Math Level Builder
1. Identify the math skill.
2. Verify the correct answer before coding.
3. Create plausible distractors.
4. Integrate the problem into a game mechanism.
5. Preserve A/B/C input.
6. Provide visible correct/incorrect feedback.
7. Progress from easier to harder tasks.
