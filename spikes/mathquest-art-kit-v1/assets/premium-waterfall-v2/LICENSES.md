# Runtime asset provenance

## Math Explorer Ranger V2

`math-explorer-quaternius-ranger-v2.glb` is derived from the free Quaternius
Universal Animation Library and Modular Character Outfits — Fantasy sources.
Those source packs are released under CC0 1.0 Universal:

- https://quaternius.com
- https://creativecommons.org/publicdomain/zero/1.0/

The MathQuest export, clip naming, lateral derivatives, Math Compass attachment
points and runtime calibration are project integration work.

## Premium Waterfall Sanctuary V2

`premium-waterfall-sanctuary-v2.glb` is a project-authored environment export.
Its terrain, waterfall, foam, hydraulic supports and bridge evolution are
documented in this directory's `README.md` and in the V1 asset inventory.
No paid runtime asset or third-party executable script is embedded.
