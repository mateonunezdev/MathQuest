# MathQuest

Juego interactivo para una feria de matemáticas.

## Stack
- HTML
- CSS
- JavaScript vanilla
- Canvas 2D

## Controles obligatorios
- Movimiento: WASD y flechas.
- Respuestas: A, B, C.
- Conservar A/B/C porque luego Arduino enviará esas teclas.

## Reglas
- Leer archivos relevantes antes de editar.
- Hacer cambios pequeños y comprobables.
- No reescribir archivos completos sin necesidad.
- No instalar librerías sin necesidad.
- Probar después de cambios importantes.
- Mantener el juego ejecutable.
- Prioridad: juego funcional > claridad > estética > complejidad.
